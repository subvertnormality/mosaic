Rhythm Doctor

Select the fifth pattern algorithm at grid column 16, row 2 to capture, analyse and paint rhythm lanes.

GestureWhat happens
With the sequencer stopped, choose Rhythm Doctor at grid (16,2).Open capture and paint. Recording, capture setup and Alignment require stopped transport; a finished bank can be browsed and painted while playing.
Empty bank: grid (1,2)Start Record. Press again or use K3 after ENOUGH / REC OR K3 to finish.
Record before enough audio, or Record on an occupied bankOpen an abandon/clear question; K2 cancels and K3 confirms. Clearing a bank preserves already painted patterns.
Before capture: E2/E3 edit setup → K3 confirm; K2 cancels.Record uses the confirmed setup. Stereo records both inputs separately; L duplicates the left input and R duplicates the right input into both recorded channels. Manual uses the selected integer BPM from recording start; Auto estimates tempo and phrase start.
Ready bank: select a lane, then E2 field → E3Browse Window bar/step, sensitivity or paint policy.
In a locally analysed READY bank, press grid (3,2), (4,2) or (5,2).Select BD (bass drum), SD (snare drum) or CYM (hi-hats and cymbals). The default local detector produces these three lanes; the remote server can declare additional lanes.
Ready bank: select Alignment → K3Open the tempo, Start beat and fine-start draft. E2 chooses the field; E3 edits. K3 reanalyses the retained recording with the confirmed alignment; K2 cancels. Manual Start beat uses regular confirmed-tempo beats; Auto uses detected beats.
Grid (10,8) / (12,8); hold for a phraseMove the recording window one step backward / forward, or a whole four-bar phrase.
Grid (11,8)Return the window to its calculated phrase start.
Select destination pattern in row 1 → grid (16,8) twicePreview the selected lane, then paint it; grid (14,8) cancels the preview.
If local analysis cannot compile its detector, check the local C compiler before another capture.ANALYSIS_BACKEND_UNAVAILABLE is shown and no bank is produced. The default worker builds the detector from shipped source; it needs python3 and a C compiler, with no third-party Python packages.
