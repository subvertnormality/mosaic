# Proposed information architecture

Only Masks is a finished pilot feature; other entries are a plan, not empty published pages.

| Reader job | Route | Planned content |
|---|---|---|
| Learn | Start here | Install → choose an output → first four notes → save |
| Do | Workflows | Build rhythm → shape harmony → write melody → modulate → arrange |
| Look up | Reference | Stable `#feature-id` for every inventory entry; controls and inheritance tables |
| Recall | Quick reference | Dense view of the same feature data; link to the existing cheat sheet |
| Understand | Musical cookbook | Syncopation, polymeter, swing, ghost notes; voice leading and tension; motif and variation |

Pilot route: `manual/index.html#masks`. The page contains route instructions, scenes, reference, cookbook and listening example. Full inventory is downloadable and searchable from the page.

Expansion path: keep IDs immutable; review authored prose and scenes feature by feature; require verified captures before publishing an interactive scene. Legacy manual links resolve to README until their replacements are accepted. Relative links preserve the existing root Pages layout, cheat_sheet.html and config_creator.html.
